# 🏛️ Austin City Council Meeting Monitor

> Automated AI-powered summaries of Austin City Council meetings — published at **[austincouncil.app](https://austincouncil.app)**

A civic media tool that monitors the Austin City Council Meeting Info Center for new meetings, downloads agenda PDFs, generates plain-language summaries using Google Gemini AI, and publishes them to a searchable public website with email alerts.

---

## 🌐 Live Site

**[austincouncil.app](https://austincouncil.app)** — searchable meeting summaries, updated automatically twice daily

- Filter by meeting type (Regular, Work Session, Committee)
- Keyword search across all meeting content
- Email subscription for new meeting alerts
- [RSS Feed](https://austincouncil.app/feed.xml) for news readers

---

## How It Works

```
austintexas.gov/council/meetings
        │
        ▼
  GitHub Actions (2x daily)
        │
        ├─ Scrape meeting links (pattern: /YYYYMMDD-type)
        ├─ Download agenda PDFs
        ├─ Extract text (PyMuPDF)
        ├─ Summarize with Gemini 2.5 Flash
        ├─ Save to SQLite database
        ├─ Send email alerts via Resend
        ├─ Regenerate static HTML/RSS
        └─ Commit & push to GitHub → austincouncil.app
```

**Update frequency:** 8:00 AM and 6:00 PM CT daily

## Tech Stack

| Layer | Technology |
|---|---|
| Scraping | Python + BeautifulSoup + Requests |
| PDF extraction | PyMuPDF |
| AI summarization | Google Gemini 2.5 Flash |
| Database | SQLite (committed to repo for persistence) |
| Email alerts | Resend API |
| Subscribe endpoint | Vercel (Python/Flask serverless) |
| Static site | Pure HTML/CSS/JS, generated by Python |
| Hosting | GitHub Pages → austincouncil.app |
| Automation | GitHub Actions (cron schedule) |

## Running Locally

```bash
git clone https://github.com/cyowell/austin-meeting-monitor
cd austin-meeting-monitor
pip install -r requirements.txt

# Set your Gemini API key
export GEMINI_API_KEY="your-key-here"

# Run the scraper
python3 austin_meeting_monitor_gemini.py

# Regenerate the website
python3 github_pages_publisher.py

# Open docs/index.html in your browser
```

## Data & Methodology

Meeting data is sourced from the [City of Austin Meeting Info Center](https://www.austintexas.gov/council/meetings). Summaries are AI-generated and should not be used as a substitute for official meeting records. See [austincouncil.app/about](https://austincouncil.app/about) for full methodology and limitations.

## For Journalists & Researchers

- **RSS Feed:** `https://austincouncil.app/feed.xml`
- **Raw data:** The `austin_meetings.db` SQLite file is committed to this repo and updated with each run
- **Database schema:** `meetings` table — `meeting_id`, `date`, `meeting_type`, `meeting_url`, `agenda_url`, `gemini_summary`, `created_at`, `notified_at`
- **Attribution:** Please credit *Austin Council Monitor (austincouncil.app)* if citing summaries
